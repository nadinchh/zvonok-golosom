# Звонок голосом

Офлайн-приложение для Android для незрячего человека. Долгое нажатие «громкость вниз» → «Кому позвонить?» → «жене» → «Позвонить Татьяне?» → «да» → звонок. Интернет не нужен.

## Как получить APK
1. Загрузить эту папку в репозиторий на GitHub.
2. Вкладка **Actions** → «Собрать APK» сам запустится (или Run workflow).
3. Через 5–10 минут скачать артефакт **ZvonokGolosom-apk** (внутри app-debug.apk).

## Установка на телефон
1. Скопировать app-debug.apk на телефон и открыть; разрешить «установку из неизвестных источников».
2. Открыть «Звонок голосом», разрешить микрофон, контакты и звонки.
3. «Настройки (для родных)»: включить службу кнопки громкости, вписать подсказки (жена = …, такси = …), скачать офлайн-голос в «Синтезе речи».
4. Нажать «Проверить».
